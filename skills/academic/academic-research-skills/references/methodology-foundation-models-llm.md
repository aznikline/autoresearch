# Foundation Model Methodology

Record exact model/checkpoint, tokenizer, prompt template, decoding, context,
tools, dataset version, evaluator and judge versions. Test contamination and
memorization. Use repeated sampling and uncertainty. Validate model judges with
independent evaluators or declared human review, including position/order bias.
Report task quality, calibration, safety, latency, throughput, tokens, memory,
compute, and cost when the claim touches them.
