# NLP Methodology

Record corpus identity, license, language/domain coverage, normalization,
tokenization, splits, annotation protocol, model/prompt versions, and evaluator
scripts. Check contamination and privacy. Use human or task-valid evaluation
when automatic metrics do not support the claim. Report uncertainty, agreement,
language and demographic subgroups, error types, negative outcomes, compute,
latency, and cost.
