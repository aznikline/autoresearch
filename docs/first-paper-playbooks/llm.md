# LLM First-Paper Playbook

Use profile `foundation-models-llm`. Freeze model/checkpoint, tokenizer, prompt
hash, decoding, context/tool policy, evaluator versions, budget, and stopping
rule before confirmatory runs. Register model and benchmark rights and hashes.

Run contamination/memorization checks, matched-access baselines, repeated
sampling, uncertainty, safety and calibration checks, and token/latency/cost
accounting. A model judge requires an independent evaluator form or human
validation plus position/order-bias controls. Scope capability claims to the
tested models, prompts, benchmarks, and access assumptions.
