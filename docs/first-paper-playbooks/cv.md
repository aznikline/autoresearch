# Computer Vision First-Paper Playbook

Use profile `computer-vision`. Freeze dataset version and split hash,
preprocessing, augmentation, resolution, pretrained checkpoint/data provenance,
evaluator hash, seeds, tuning budget, and stopping rule.

Check duplicate/pretraining leakage and match training resources across strong
baselines. Report task metrics with uncertainty, calibration, robustness,
subgroups, latency, memory, and compute as applicable. Select qualitative
successes and failures by a declared policy; cherry-picked panels cannot enter
the evidence graph.
