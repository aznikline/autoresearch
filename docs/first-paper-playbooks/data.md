# Data And Database First-Paper Playbook

Use profile `data-management-mining`. Freeze system versions, schema/workload
hashes, scale, indexes, optimizer settings, storage/hardware, concurrency,
isolation, cache/warm-up policy, repetitions, timeouts, and correctness oracle.

Compare tuned systems on matched hardware. Preserve queries, plans, logs,
timeouts, failures, and resource traces. Report latency distributions and tail
behavior, throughput, correctness, resource use, and cost rather than only a
mean. Mining experiments additionally require temporal/split leakage controls,
uncertainty, reproducible features, and subgroup/error analysis.
