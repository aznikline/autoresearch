# NLP First-Paper Playbook

Use profile `natural-language-processing`. Freeze corpus version, languages,
domains, split hash, normalization, tokenization, annotation protocol,
evaluation script, model/prompt versions, budget, and stopping rule. Resolve
corpus/generated-data license and privacy status before execution.

Align every generalization with observed language and demographic coverage.
Complement limited automatic metrics with task-valid human evaluation, retain
disagreements and negative cases, and report significance, contamination,
subgroup outcomes, and error categories.
